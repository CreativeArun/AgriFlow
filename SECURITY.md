# Security Policy

## Supported Versions

We currently support security fixes for the latest version of AgriFlow available on the `main` branch.

| Version | Supported |
| ------- | --------- |
| Latest (`main`) | ✅ |
| Older versions | ❌ |

## Reporting a Security Vulnerability

If you discover a security vulnerability in AgriFlow, please report it privately rather than creating a public GitHub issue.

Please contact the project maintainers at:

**[arunverma635472@gmail.com]**

When reporting a vulnerability, please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected component or service
- Potential impact
- Any relevant screenshots, logs, or proof-of-concept details

Please do not publicly disclose the vulnerability until the maintainers have had an opportunity to investigate and address it.

## Security Guidelines

When contributing to AgriFlow:

- Never commit API keys, access tokens, passwords, or database credentials.
- Never commit `.env` files containing secrets.
- Use environment variables for sensitive configuration.
- Do not include private credentials in source code, logs, screenshots, or documentation.
- Report suspected vulnerabilities privately to the maintainers.

## Scope

Security reports may concern any part of the AgriFlow platform, including:

- Spring Boot backend
- FastAPI AI services
- Frontend application
- REST APIs
- Database configuration
- Authentication and authorization
- Third-party AI/ML API integrations
- Deployment and configuration

Thank you for helping us keep AgriFlow secure.
